## 🚀 About Me

I specialize in building intelligent, agentic AI applications, local LLM tooling, and production-grade web systems. My work focuses on bridging local AI models (Ollama, llama.cpp, Gemma 3, DeepSeek) with real-world applications—ranging from financial compliance engines and market intelligence dashboards to dark web OSINT threat investigation frameworks.

- 🔭 **Currently Building**: Agentic AI workflows, privacy-first offline LLM tools, and real-time data intelligence platforms.
- 🧠 **Areas of Interest**: Vision-Language Models (VLM), Deep Reasoning (CoT), Local LLM Inference, Web Crawling & Automation, Threat Intelligence.
- ⚡ **Philosophy**: High performance, clean architecture, privacy by default, and user-first design.
